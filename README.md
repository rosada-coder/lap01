# OOP Lab 01 – Student Profile

## รายละเอียดโปรเจกต์
โปรเจกต์นี้เป็นส่วนหนึ่งของรายวิชาการเขียนโปรแกรมเชิงวัตถุ (Object-Oriented Programming: OOP) จัดทำขึ้นเพื่อฝึกการเขียนโปรแกรมด้วยภาษา TypeScript และเรียนรู้การใช้งาน Node.js, VS Code, Git และ GitHub

## วัตถุประสงค์
- เพื่อเรียนรู้พื้นฐานภาษา TypeScript
- เพื่อฝึกสร้าง Object และ Method
- เพื่อเรียนรู้การใช้คำสั่ง `console.log()` แสดงผลข้อมูล
- เพื่อฝึกใช้งาน Git และ GitHub ในการจัดเก็บโค้ด

## เครื่องมือที่ใช้
- Visual Studio Code
- Node.js เวอร์ชัน 20 ขึ้นไป
- TypeScript
- tsx
- Git และ GitHub

## โครงสร้างไฟล์
```text
oop-lab-01/
├── profile.ts
├── profile.js
└── README.md
```

## วิธีการติดตั้งและใช้งาน

**1. ตรวจสอบเวอร์ชัน Node.js**
```bash
node -v
```

**2. เปิดโปรเจกต์ใน VS Code**

**3. รันโปรแกรม TypeScript**
```bash
npx tsx profile.ts
```

**4. ผลลัพธ์ที่ได้**

```text
=== ข้อมูลนักศึกษา ===
[66010001] สมชาย ใจดี - เทคโนโลยีดิจิทัลเพื่อธุรกิจ (ปี 2)
```
